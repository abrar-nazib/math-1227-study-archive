## Layout

- `questions/` contains one OCR transcription per year.
- `sources/` contains the original PDF and JPEG images.
- `sources/images/` holds the JPEG pages. The 2024 screenshots duplicate the PDF's 2024 pages, so their questions appear only once in `questions/2024.md`.

## Study flow

1. Start with a recent paper and solve it closed-book.
2. Use older papers to target weak topics.
3. Check source images only when a question is marked `[Source-faded]`; no unreadable notation has been guessed.
